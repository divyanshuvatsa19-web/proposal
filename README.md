# 💖 Cinematic Interactive Proposal Experience

A deeply intimate, aesthetic, and cinematic web application crafted to ask the most important question of your life in an unforgettable way. Built with modern web standards, smooth particle physics, and Web Audio API synthesis — completely self-contained in a single lightweight file with **zero external dependencies**.

---

## ✨ Features & Highlights

### 🎬 1. Chapter-by-Chapter Storytelling
* **Prologue — "Before You":** An emotional cinematic cold open setting a heartfelt tone.
* **Chapter I — The Little Things (Scrapbook Cards):** Elegant flip cards celebrating her irreplaceable quirks, her laughter, and what makes her your home.
* **Chapter II — My Vows:** Three sincere, grounded promises to protect her peace, celebrate her wins, and choose her in every lifetime.
* **Chapter III — The Question:** A breathtaking reveal (*"Will You Be Mine? 💍"*) featuring:
  * An evasive, playful **"No"** button that dodges the cursor/finger with sweet affectionate pleas.
  * A gently growing **"Yes, A Thousand Times Yes 💖"** button.
* **Chapter IV — The Sparkling Grand Finale:** A radiant 1-line declaration (*"You Are My Whole Universe, Forever & Always 💖"*), followed by an illuminated *"I love you 💖"* while celebratory fireworks and star sparkles burst across the screen.

---

### 🎨 2. Aesthetic & Visual Design
* **Cinematic Letterbox & Grain:** Real procedural SVG film grain and smooth cinematic letterbox framing.
* **Ambient Bokeh Orbs:** Drifting, warm gold and soft rose ambient light blobs in the background.
* **Interactive Touch & Cursor Sparkles:** Moving a finger or mouse emits twinkling 4-pointed diamond stars and mini hearts (`✨💖`).
* **Physics-Based Fireworks & Crackers:** Multi-layered canvas cracker bursts with glittering spark trails, gravitational pull, and starburst flares.

---

### 🎶 3. Built-In Romantic Music & Sound FX
* **Synthesized Web Audio API:** No broken audio links or external `.mp3` dependencies.
* **Romantic Piano/Celeste Arpeggio:** Loops an emotional chord progression in the background.
* **Aesthetic Sound Wave Indicator:** Interactive pill at the top-right to toggle audio on/off anytime.
* **Cracker Burst Pops:** Synthesized sound effects synchronized with visual firecracker bursts.

---

### 📱 4. 100% Mobile-First & Responsive
* **Device Adaptive:** Looks stunning on every screen size from small phones (iPhone SE, Galaxy, Pixel) up to 4K desktop displays.
* **Touch-Optimized:** Safe-area insets (`env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`), touch-event bounds for the moving button, and smooth momentum scrolling.

---

## 🚀 Quick Start / How to Run

Because this project is written in pure vanilla HTML, CSS, and JavaScript:

1. **Local View:**
   * Double-click `index.html` or drag it into any modern web browser (Chrome, Safari, Edge, Firefox).
2. **On Mobile:**
   * AirDrop / transfer `index.html` to your phone and open in Safari/Chrome, or host it online.

## 🌐 Free 1-Click Hosting / Deployment

You can host this online for free so you can send her a link:

### Option A: GitHub Pages (Recommended)
1. Push this folder to a GitHub repository.
2. In your repository, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. GitHub will give you a live link (e.g., `https://your-username.github.io/proposal/`).

### Option B: Netlify / Vercel
* Drag and drop the `proposal` folder directly into [Netlify Drop](https://app.netlify.com/drop) for an instant live URL.

## 🛠️ Personalization & Customization

Want to tweak the text or add personal inside jokes? Open `index.html` in any text editor (like VS Code or Notepad):

| Feature | Location in `index.html` |
| :--- | :--- |
| **Intro Text** | Search for `<!-- CHAPTER 1: THE INTIMATE PROLOGUE -->` |
| **Memory Cards** | Search for `<div class="love-card"` (Cards 1 to 5) |
| **Promises** | Search for `<!-- CHAPTER 3: INTIMATE PROMISES -->` |
| **Finale Headline** | Search for `<h1 class="one-line-headline">` |
| **Finale Love Line** | Search for `<div class="final-love-line">` |
